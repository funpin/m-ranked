# Набор кастомных эмодзи m-ranked (Remotion)

Фирменные значки Telegram-бота: логотип, площадки, места, рост и падение,
«продвижение», «накрутка», «выстрелил», срочная тревога и плашки-разделители
(«НАШИ ЛУЧШИЕ», «НЕДЕЛЯ» и др.) из пяти эмодзи подряд с надписью внутри.
Цвета, шрифты (Geologica, JetBrains Mono) и знак — с сайта; логотипы площадок —
официальные (`frontend/public/brands`), без изменений формы и цвета.

Требования Telegram к кастомным эмодзи: ровно 100×100; неподвижные — PNG (у нас все анимированные);
анимированные — WebM VP9 с прозрачностью, до 3 с, до 30 к/с, до 64 КБ (на 78 КБ
Telegram отвечает STICKER_VIDEO_BIG; лимит 256 КБ — для обычных стикеров).

## Посмотреть

```bash
npm i
npx remotion studio      # композиция «sheet» — весь набор в сообщении, тёмная и светлая тема
```

## Пересобрать файлы

```bash
bash scripts/render-all.sh   # → out/emoji/: 59 WebM (плашки режет scripts/slice.sh, нужен ffmpeg)
```

## Загрузить в Telegram

Файлы `out/emoji/` и `emoji-manifest.json` копируются на Сервер 2, где лежит
токен бота, и загружаются скриптом `operations/scripts/create-bot-emoji-set.py`
(владелец набора — админ бота). Скрипт печатает JSON «слот → id»; его кладут
на сервере в `/etc/m-ranked/telegram-bot-emoji.json` (или по пути из
`TELEGRAM_BOT_EMOJI_IDS_FILE`) и перезапускают бота — он начинает ставить
кастомные эмодзи вместо обычных. В репозиторий этот файл не кладут: по id
эмодзи Telegram отдаёт имя набора, а в нём — имя бота. За каждым эмодзи закреплён тот же обычный эмодзи, что в слоте бота
(`telegram_bot/emoji.py`) — его показывают уведомления и пересылка.
