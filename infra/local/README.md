# Локальная проверка текущей версии

Стенд собирает текущие исходники Next.js и Spring в Docker и запускает их
с PostgreSQL 18.6 и Redis 8.10.0. Все опубликованные порты привязаны к `127.0.0.1`.

- Интерфейс: http://localhost:3000
- Управление: http://localhost:3000/manage
- API: http://localhost:8080/api/v1/health/ready
- Локальный администратор: `admin`, пароль `local-review-2026`.

Это отдельная локальная учётная запись. Пароли из `compose.env` предназначены
только для этого стенда.

## Данные

По просьбе пользователя импорт окончательно остановлен. Активная база содержит
**1 908 публикаций, 97 000 замеров, 66 вузов и 261 аккаунт**.
Замеры: VK — 65 110, MAX — 29 482, Rutube — 2 408. Метаданные Telegram
сохранены, но его замеры не успели загрузиться. История неполная; для начала
проверки откройте http://localhost:3000/?platform=vk&period=30d.
Это не полные 10% базы и не результат полной сверки с production.

Исходный бэкап находится в `data/local-review/source.sqlite`; его SHA-256
сверен с серверным и записан в `source.sha256`. Скрипт `infra/local/sample.py`
создаёт отдельный `sample-10.sqlite`, проверяет целостность и внешние ключи,
записывает SHA-256 и манифест выборки. Исходный бэкап не меняется.
Выборка `sample-10.sqlite` содержит 375 896 замеров, однако в активную базу
`mranked_review10` попали только указанные выше 97 000. Дальнейший импорт
отключён через `LOCAL_IMPORT_ENABLED=false`, включая повторные запуски.
Папка `data/` исключена из Git и контекста Docker-сборки. В контейнер импортера
копия подключена только для чтения; внутри образов её нет.

Использован плановый бэкап `reactions-20260906T001759Z.db` от 6 сентября 2026 года,
03:18 МСК. В нём реальные данные на момент резервного копирования.
При скачивании нужно сохранять mtime (`scp -p`), используемый bridge как время снимка.

PostgreSQL создаётся сразу из единой финальной схемы. После остановки `finalize_partial.py` построил
проекции только по уже зафиксированным записям. Batch имеет статус `cancelled`,
collection run — `partial`. Отчёт `partial-dataset.json` и маркер
`seed-complete.json` сохранены в volume `import_10_state`; полной сверки нет.
Контейнер seed проверяет маркер и завершается без импорта, разрешая запуск Next.js.
Без маркера при отключённом импорте он завершится ошибкой, не начнёт перенос.
Адрес `localhost:3000` обслуживает Nginx. Сам Next.js доступен для диагностики
на `localhost:3002`. Контейнер прогресса выключен и вынесен в отдельный профиль.
Повторные запуски сохраняют локальные изменения; другая исходная копия
не импортируется поверх существующих данных автоматически.

Локальные изменения в панели не передаются на production. Сборщики площадок
и автоматическое обновление официального М-Рейтинга не запускаются;
токены, браузерные профили и пользовательские сессии production не копируются.

### Локальное исключение схемы для реальной базы

В полной production-копии у 229 Telegram-публикаций (в выборке — у 21) одновременно установлены
`baseline_from_publication=1` и `history_forced_incomplete=1`. Legacy считает
эти признаки независимыми; его формулы периодов и V29-проекции используют
сохранённый baseline. Ограничение `publication_check1` из V1 запрещает
такое сочетание и останавливает штатный импорт.

Только в этом локальном PostgreSQL импортер заменяет ограничение на
`publication_local_legacy_baseline_check`, допускающее baseline при
`complete` и `forced_incomplete`. Оба исходных значения сохраняются,
Исходные значения SQLite и финальная схема не редактируются. Изменение записано в
`local-schema-adjustment.json` в volume `import_10_state`.
Стенд поэтому не является проверкой неизменённой production-схемы;
для реального перехода нужен отдельно проверенный новый финальный контракт схемы.

## Команды из корня репозитория

Команды ниже используют уже подготовленные volumes. Новый импорт не запускается.
Не удаляйте volumes, если хотите сохранить этот стенд и локальные изменения.

```bash
rtk proxy bash infra/local/stack.sh up -d --build
rtk proxy bash infra/local/stack.sh ps -a
rtk proxy bash infra/local/stack.sh logs --tail=100 api web seed
rtk proxy bash infra/local/stack.sh stop
rtk proxy bash infra/local/stack.sh up -d
```

Остановка сохраняет PostgreSQL, Redis, файлы экспорта и результаты импорта
в именованных Docker volumes проекта `mranked-local`.
Остановленный первоначальный полный импорт остаётся в отдельной базе `mranked`
и не используется стендом с выборкой.
