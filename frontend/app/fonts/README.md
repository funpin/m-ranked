# Шрифты сайта

Шрифты лежат в репозитории, чтобы сборка не зависела от Google Fonts
(18.10.2026 CI упал, когда Google не отдал файлы). Файлы `.woff2` — ровно те,
что `next/font/google` нарезал в рабочей сборке: по наборам символов
(кириллица, латиница, расширенные наборы) с `unicode-range`, поэтому браузер
грузит те же байты, что и раньше.

| Семейство | Переменная | Где | Заранее (preload) |
|---|---|---|---|
| Geologica | `--font-heading` | весь сайт | кириллица, латиница |
| Onest | `--font-sans` | весь сайт | кириллица, латиница |
| JetBrains Mono | `--font-mono` | весь сайт | нет |
| Unbounded (500–600) | `--font-display` | только главная | кириллица, латиница |

- `faces.json` — наборы: файл, диапазон символов, preload; метрики запасных шрифтов.
- `fonts.ts`, `landing-fonts.ts`, `fallbacks.css` — генерирует
  `node scripts/generate-fonts.mjs` из `faces.json`; руками не править
  (тест `tests/fonts.test.ts` сверяет).
- Лицензия всех четырёх — SIL OFL 1.1, тексты рядом: `OFL-<семейство>.txt`.

Новый набор или начертание: положить `.woff2`, добавить строку в
`faces.json`, запустить генератор, сравнить вес и preload страниц до и после.
