# API-интеграции m-ranked

Обновлено: 30 августа 2026.

Секреты задаются только в серверном `.env`, которому нужны права `600`. Их
нельзя вводить через веб-панель, добавлять в Git, логи или скриншоты. Интерфейс
показывает только состояние «подключено / нужна настройка».

## Telegram

Публичный режим `DATA_SOURCE=public_web` не требует API-токена, но даёт только
публично отображаемые показатели. Для точного MTProto-сбора нужны:

```dotenv
DATA_SOURCE=mtproto
TELEGRAM_API_ID=...
TELEGRAM_API_HASH=...
TELEGRAM_SESSION_PATH=data/telegram.session
```

`API ID` и `API hash` создаются для аккаунта на `my.telegram.org`. После этого
один раз выполняется `.venv/bin/python -m app auth`; файл сессии также является
секретом и не должен попадать в Git.

## ВКонтакте

```dotenv
VK_ACCESS_TOKEN=...
VK_API_VERSION=5.199
```

Сборщик использует read-only методы `groups.getById`, `wall.get` и
`wall.getById`. В базу пишутся просмотры, likes, комментарии и репосты.
Отсутствие токена полностью отключает VK-опрос, не затрагивая другие площадки.

## MAX

```dotenv
MAX_ACCESS_TOKEN=...
MAX_API_BASE=https://platform-api2.max.ru
```

Токен выдаётся созданному MAX-боту. Бота необходимо назначить администратором
каждого канала и дать право `read_all_messages`. Помимо токена для каждого
MAX-аккаунта в `/manage` заполняется числовой `chat_id`; публичной ссылки для
чтения Bot API недостаточно. Сборщик сохраняет только счётчики, фактически
полученные в `stat`; недоступные значения остаются `NULL`.

## Rutube

```dotenv
RUTUBE_PUBLIC_API_ENABLED=true
RUTUBE_API_BASE=https://rutube.ru/api
```

Официальный публичный JSON-фид видео не требует токена и отдаёт `hits`
(просмотры). Универсального публичного токена для likes/comments не найдено:
эти показатели не выдумываются и остаются `NULL`. Если Rutube предоставит
владельческий или партнёрский доступ к Studio API, он должен быть подключён
отдельным адаптером и с отдельным набором прав.

## Проверка после установки секретов

```bash
.venv/bin/python -m app poll-now
curl -fsS http://127.0.0.1:8090/health
```

`/health` показывает только булевый статус конфигурации, время, длительность и
число ошибок последнего цикла каждой площадки. Значения токенов туда не входят.
