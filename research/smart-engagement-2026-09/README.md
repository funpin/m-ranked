# Детекция аномалий: состояние работы

Цель — достаточно точный, проверенный на будущих данных сигнал необычной динамики публикации, затем аккаунта и вуза, отдельно для Telegram, VK, MAX и RuTube. Сигнал по счётчикам **не доказывает накрутку**.

## Что работает сейчас

- Публичный анализатор v2 использует эвристики. Для позднего роста Telegram и MAX контекст соседних публикаций может понизить итоговый уровень; исходный сигнал остаётся виден. Это не калиброванная вероятность ошибки.
- Код M0 записывает успешные чтения постов, включая неизменившиеся значения, для ограниченной opt-in когорты. Он выключен по умолчанию; в локальной копии таких записей пока нет.
- Исследовательский M1 сравнивает реальные интервалы с возрастной нормой, M2 добавляет положение нового поста в ленте и его видимый охват. Есть постовой расчёт на заранее выбранных горизонтах. Ни один из этих вариантов пока не допущен к публичной оценке.
- На локальном архиве MAX выполнен воспроизводимый прогон. Он **не подтвердил улучшение M2** и не измерил точность: архив сохранял преимущественно изменения счётчиков и не содержит полного набора успешных чтений.
