# Детекция аномалий: состояние работы

Цель — достаточно точный, проверенный на будущих данных сигнал необычной динамики публикации, затем аккаунта и вуза, отдельно для Telegram, VK, MAX и RuTube. Сигнал по счётчикам **не доказывает накрутку**.

## Последняя проверка: 28.09.2026

[EXPERIMENTS.md](EXPERIMENTS.md) — 12 проверенных гипотез, 8730 постов / 96 аккаунтов, более 2 млн архивных снимков и временной контроль на 1015 постах после точечного обновления. [SOURCES.md](SOURCES.md) — разбор всех 12 приложенных статей и дополнительных первоисточников.

Платформенная возрастная модель улучшила прогноз относительно общей; преимущество расширенного контекста не подтверждено. Воспроизведены контрпримеры к недодисперсии после интерполяции, восстановлению нулей по обходам аккаунта, интерпретации синхронности и правилу R≤V при Star-реакциях. Проверены чувствительность к увеличению конечного счётчика, сохранение ER при пропорциональном увеличении и математическая граница неидентифицируемости. Производственный код не менялся; новые модели остаются исследовательскими.

## Что работает сейчас

- Публичный анализатор v2 использует эвристики. Для позднего роста Telegram и MAX контекст соседних публикаций может понизить итоговый уровень; исходный сигнал остаётся виден. Это не калиброванная вероятность ошибки.
- Код M0 записывает успешные чтения постов, включая неизменившиеся значения, для ограниченной opt-in когорты. Он выключен по умолчанию; в исследовательской копии 27.09 найдено 44 записи примерно за 16 минут. Этого недостаточно для валидации полной когорты; фактическая текущая конфигурация прода здесь не установлена.
- Исследовательский M1 сравнивает реальные интервалы с возрастной нормой, M2 добавляет положение нового поста в ленте и его видимый охват. Есть постовой расчёт на заранее выбранных горизонтах. Ни один из этих вариантов пока не допущен к публичной оценке.
- На локальном архиве MAX выполнен воспроизводимый прогон. Он **не подтвердил улучшение M2** и не измерил точность: архив сохранял преимущественно изменения счётчиков и не содержит полного набора успешных чтений.
