# Эталон постов ВК

Размеченный набор для проверки порогов признаков ВК: `posts.csv`, одна строка на пост.
Класс описывает форму публичных счётчиков и нужен только для калибровки. Это не вывод о вузе
и не утверждение о происхождении активности (ADR-006).

| Поле | Значение |
|---|---|
| `publication_id` | идентификатор поста |
| `class` | `organized_audience`, `external_promotion`, `view_bursts`, `reaction_waves`, `organic`, `timezone_shift`, `federal` |
| `status` | `confirmed` или `disputed`; спорные в расчёт точности не входят |
| `source` | `form` — правило по форме и просмотр графика; `owner_test` — оплаченное продвижение, известное владельцу |
| `reason` | почему пост получил этот класс, с числами |

## Как собран

Посты ВК с 01.09 по 03.11.2026, полные 72 часа, не меньше 200 просмотров, без репостов, видео
и клипов. Отбор детерминирован (`build_reference.py`, seed 20261108), равномерно по аккаунтам.
Органика — 10 случайных аккаунтов, которые не выше медианы площадки минимум по 11 метрикам из 14,
без находок и вне архетипов исследования.

Доля реакций внутри всплеска намеренно не участвует в правилах: это величина, которую проверяет
следующий этап. Эталон, отобранный по ней, подтверждал бы сам себя.

| Класс | Подтверждён, если |
|---|---|
| `organized_audience` | ERV ≥ 2,5× медианы площадки, ≥ 5 комментариев, просмотры без ступеней и обрыва, за один час не больше половины реакций |
| `external_promotion` | охват на подписчика ≥ 20 %, поздний старт или ровный дневной участок от 6 ч, нет дневного обрыва; плюс пять постов теста владельца |
| `view_bursts` | ступень просмотров после второго часа и дневной обрыв, поздний старт или ровный участок сквозь ночь |
| `reaction_waves` | пост в часе, когда реакции получили ≥ 10 старых постов аккаунта, просмотры без ступеней |
| `organic`, `timezone_shift`, `federal` | нет ступеней, обрыва и позднего старта |

Графики всех постов просмотрены 08.11.2026 по классам. Просмотр дал два исправления правил и
шесть постов `disputed` с причиной «при просмотре графика».

## Ограничения

- Единственная независимая разметка — пять постов теста владельца. Остальные классы опираются
  на форму и выводы исследования; `external_promotion` — гипотеза, а не известный факт.
- Проверка по API ВК при сборке не проводилась: ручные проверки исследования были на уровне
  аккаунта и не привязаны к конкретным постам.
- Пороги, подобранные на этом наборе, относятся к тому же периоду, где признаки были найдены.

## Пересборка

На локальной копии с схемой `rvk` (`../scripts/build_vk.sql`): выгрузка `../scripts/export_vk.sql`
в каталог `data/`, затем `../scripts/features.py` и `../scripts/agg.py` из его родителя, затем
`python build_reference.py data posts.csv`.
