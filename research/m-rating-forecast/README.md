# Бэктест прогноза М-Рейтинга

Прогноз опубликованных месяцев тем же модулем, что считает ночной снимок
(`api/rating_forecast.py`), против официальных баллов. Нужен, чтобы видеть,
когда пороги формулы уехали и пора выпускать новую версию
(`rating.formula_definition`, спек
`docs/superpowers/specs/2026-10-16-rating-forecast-design.md`).

## Запуск

Источник — официальный файл `ratings-2026.json` с m-rating.ru, скачанный в
отдельный каталог. База — локальная копия прода (только чтение).

```bash
python -I research/m-rating-forecast/backtest.py --dsn "<DSN локальной копии>" --source <каталог>/ratings-2026.json --months 2026-08,2026-09
```

База каждого месяца — предыдущий опубликованный: из него берутся баллы
неотслеживаемых вузов, подмена при неполных данных и смесь Rutube. Типичные
ошибки — значения по умолчанию из `FORMULA_V1`.

## Когда выпускать версию 2

Если у опубликованного месяца MAE соцсетей больше 9 или ρ меньше 0.7 —
перебрать пороги на последних двух месяцах и записать новую версию формулы
(новая строка `rating.formula_definition`, `FORMULA_V2` в модуле); снимки
версии 1 остаются объяснимыми своей версией.
