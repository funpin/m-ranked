# ADR-001: Модульный монолит

- Status: **Accepted**
- Date: 2026-09-13
- Owners: architecture / backend

## Context

M-Ranked обслуживается небольшой командой и использует одну согласованную модель
наблюдений, рейтингов и каталога. Независимые network contracts и брокер между
доменами не дают измеримой пользы, но усложняют транзакции и эксплуатацию.

## Decision

M-Ranked — модульный монолит с единым release train:

1. Next.js web;
2. FastAPI public/admin API;
3. отдельный Python-процесс коллектора на платформу;
4. anomaly и maintenance workers;
5. одна PostgreSQL с границами по схемам и ролям.

Физические процессы изолируют сбои и память, но не являются независимо
версионируемыми микросервисами. Публичный контракт один — OpenAPI v1.
Запись наблюдения, lineage, dataset revision и outbox выполняется атомарно.
Внешний брокер не является условием записи или чтения.

## Consequences

- один Python toolchain для API, collectors и workers;
- platform units можно перезапускать независимо;
- согласованность обеспечивается PostgreSQL и database roles;
- масштабирование ограничено общей БД, поэтому запросы обязаны быть bounded;
- прямые зависимости между пакетами проверяются тестами и review.

## Revisit when

Решение пересматривается при независимых командах/release cadences, доказанной
необходимости отдельного масштабирования или обязательной security boundary.
