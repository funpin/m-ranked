# ADR-015: поздний отклик — пост против себя, аккаунт против площадки

- Status: **Accepted**
- Date: 2026-09-28
- Зависит от: [ADR-006](ADR-006-anomaly-terminology.md), [ADR-014](ADR-014-anomaly-analysis-v2.md)
- Реализация: `anomaly_analysis/v2/tail_ledger.py`, `detectors/late_engagement.py`,
  `v2/account_tail.py`, `account_tail_job.py`, миграция `0051`; исследование —
  [`research/smart-engagement-2026-09/TAIL_RATIO.md`](../../../research/smart-engagement-2026-09/TAIL_RATIO.md)

## Context

Повторяющийся отклик на посты возрастом 4–14 суток не виден методам, которые
сравнивают аккаунт с его историей: постоянное поведение становится нормой
(H14, MAX_TAIL §4). Исследование H13–H67 показало это на данных и отвергло
кандидатов, калиброванных на собственной или загрязнённой истории. ADR-014
откладывал сводку по аккаунту как суждение об университете.

## Decision

1. Работник строит для каждого поста компактный реестр позднего отклика (~200
   байт) из уже прочитанного ряда: ранняя точка около 24 ч, точные концы окна
   4–14 суток, московские сутки с известным чистым приростом реакций.
2. Признак поста 13 «поздняя вовлечённость выше ранней» сравнивает долю
   реакций на поздние просмотры с долей в первые сутки того же поста.
   Семейство «согласие метрик», сила не выше 0,6 — один признак даёт не больше
   слабого сигнала. Только точные счётчики.
3. Ночное задание строит профиль аккаунта: отношение K поздней доли к ранней
   по постам 4–28 суток, положение среди **других** аккаунтов той же площадки,
   устойчивость по двум половинам и по разным суткам двух недель. Статусы:
   обычный для площадки, необычный, устойчиво необычный, недостаточно данных
   (с причиной). Сильного статуса нет.
4. Владелец продукта решил 28.09.2026 публиковать профиль сразу на странице
   аккаунта, для всех площадок с собственными порогами. Это отменяет пункт
   ADR-014 об отложенной сводке по аккаунту в пределах ADR-006: профиль
   сообщает «нетипично относительно выбранной когорты», показывает числа,
   знаменатели, альтернативы и оговорку, не приписывает мотив.

## Consequences

- Постоянная добавка к старым постам больше не поглощается историей аккаунта;
  на MAX добавка в три реакции на пост даёт устойчивый статус у 12 из 20
  обычных аккаунтов, однократная сессия читателя архива — ни у одного.
- Около 10 % пригодных аккаунтов площадки по построению получают как минимум
  «необычный»: это положение в когорте, не частота ложных тревог.
- Регулярные увлечённые читатели и организованная активность по счётчикам
  неотличимы; поэтому статус не выше среднего, альтернативы обязательны.
- Нагрузка: +1,3 мс p95 на анализ поста, без новых чтений замеров; задание по
  аккаунтам читает только реестры и занимает доли секунды расчёта; ~336 строк
  профиля в сутки, хранение 90 суток.
- Telegram: округлённые счётчики допускаются только в профиль, с пометкой, и
  сравниваются только с Telegram. RuTube пока воздерживается целиком.

## Alternatives considered

- **Норма по истории аккаунта с защитой (Huber, обрезка, медиана).** Отклонено
  в H32–H35: не устраняет поглощение и поднимает ложные сигналы.
- **Независимый peer-ориентир на интервалах (H62–H64).** Отклонено: мало
  калибровочных окон, ширина ухудшает обычные сессии.
- **Ширина отклика как критерий.** Оставлена описательной: одна сессия
  читателя архива тоже распределяет реакции ровно.
