# ADR-018: время аудитории вместо ночи по Москве

- Status: **Accepted**
- Date: 2026-11-08
- Зависит от: [ADR-006](ADR-006-anomaly-terminology.md), [ADR-017](ADR-017-engagement-episodes-and-account-findings.md)
- Реализация: `anomaly_analysis/v2/audience_rhythm.py`; описание порогов —
  [`docs/research/anomaly-methods-v2.md`](../../research/anomaly-methods-v2.md), раздел 6b

## Context

Часового пояса вуза в каталоге нет. У 11 сибирских и дальневосточных аккаунтов ВК московская ночь —
утро аудитории. Находка `night_reactions` уже искала ночь по просмотрам, а признак 18 и порог ночи
находки `promotion` считали её по Москве. Плоский суточный ритм встречается и у крупных федеральных
вузов, поэтому глубина тихого окна сама по себе ничего не значит.

## Decision

| Вопрос | Решение | Почему |
|---|---|---|
| Оценка времени аудитории | Четыре подряд самых тихих часа обычной формы суток: средняя доля часа по постам без 20 % самых больших значений; сводка `hours`, сдвиг от 03:00 МСК; в профиле аккаунта | Регулярная подача не должна становиться нормой аккаунта: по сумме просмотров пакеты сдвигали окно на 2–10 часов. Новых чтений и полей сводки нет |
| Глубина ночи | Настоящие просмотры в этом окне к пику обычной формы | Ночной приток виден, а не входит в оценку ночи |
| Окно вне −1…+6 ч | Пояс неизвестен: признаков ночи нет, карточка аккаунта предупреждает | Так выглядит и приток в обычно тихие часы; судить по такому окну нельзя |
| `night_reactions` | Сдвиг ночи −6…+1 вместо −9…+1 | Те же пояса, что у времени аудитории |
| Признак 18 | 00–06 по времени аудитории; без пояса не считается | Запрет ночи по Москве без тихого окна |
| Неглубокая ночь | Необычна только при пике вне дневных часов аудитории (9…18 ч от начала окна) | ВШЭ, РАНХиГС, МФТИ: неглубокая ночь при обычном вечернем пике |
| Порог ночи у `promotion` | Домножается на долю 00–06 МСК у аккаунта к обычной 0,08 при сдвиге больше +1 | Сводка хранит только московскую ночь; менять её ради одного порога дороже |

Изменения ADR-017: диапазон сдвига `night_reactions`. Находка по-прежнему не меняет уровень поста.

## Consequences

- Сводка поста не меняется, запрос работника — один индексный на пачку с кэшем аккаунта.
- До первого ночного расчёта с ритмом работник считает аудиторию московской, как раньше.
- Если пакеты получает больше пятой части постов каждый час, обычная форма всё равно смещается.
  Отделить такой режим по одной форме нельзя, его показывают находки аккаунта.

## Alternatives considered

- **Часовой пояс в каталоге.** Отклонено на этом этапе: нужна ручная разметка, а время аудитории
  отличается от пояса вуза у федеральных и дистанционных аудиторий.
- **Отдельная раскладка 6–72 ч в сводке поста.** Отклонено: дороже по памяти и хуже отделяет
  федеральные вузы от аккаунтов с ночным притоком.
